# GB200 structural traversal reproduction

Fresh single-state reproduction on the allocated `gb-nvl-147-compute03`
`GB200:1` resource (container host `6037dea9fd3b`), 2026-09-06. The benchmark
is CPU-only. All ten benchmark processes were pinned to otherwise-idle CPU 0
with the `performance` governor; the host is AArch64, 144 one-thread
Neoverse-V2 cores, GCC 13.3.0. The container exposed NVIDIA device nodes and
CUDA 13.0.1, but NVML returned `Failed to initialize NVML: Unknown Error`, so
no unverified GPU model, driver, or memory telemetry is reported here.

The tables below are the verbatim output of the unmodified standardized
reporter at harness head `50ca6657d39a6052bcf8ae068a3917911bc2f6d4`,
using `--cpu 0 --runs 5` over both binaries. Every process completed all
untimed correctness checks before timing; hook-port fidelity separately
passed for all 23 functions against apache/tvm
`a1031a21776924cc390cf4d2e6257927487d69f5`.

These are absolute observations, not H200/GB200 deltas. The reporter's `fits`
column uses its fixed 32 KiB L1d / 1 MiB L2 / 32 MiB L3 geometry. This host
reports 64 KiB L1d, 1 MiB L2, and 114 MiB L3 per cache instance, so the emitted
`seq-256` `L2` label is conservative and should not be read as the actual
GB200 residency boundary; its 52--54 KiB declared working set fits this host's
L1d. The timings and declared byte counts are unaffected.
